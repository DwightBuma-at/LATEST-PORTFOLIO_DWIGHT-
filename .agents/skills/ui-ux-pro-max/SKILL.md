# UI/UX Pro Max

## Purpose

Elevate user experience, visual polish, component composition, and interaction clarity while respecting established project architecture.

## Activation Criteria

Activate when selecting color palettes, refining user flows, improving portfolio or dashboard UX, or auditing interaction quality.

## Specialized Instructions

- Adapt recommendations to `dwight-final-portfolio`'s existing Tailwind v4 tokens, Plus Jakarta Sans font, and shadcn/ui primitives.
- Optimize information scent, navigation clarity, and scannability across all 6 portfolio pages.
- Balance aesthetic polish with WCAG 2.2 AA accessibility and fast perceived performance.

## Implementation Standards

- Define semantic color roles (background, surface, primary, muted, accent, border) via CSS variables.
- Ensure interactive states (hover, focus-visible, active, disabled) are clear and consistent.
- Design mobile and desktop flows intentionally rather than shrinking desktop layouts.

## Verification Checklist

- Primary user journeys (navigation, project inspection, contact) are effortless.
- Contrast, typography scale, and interactive affordances are consistent.
- Light and dark themes both feel intentional.

## Anti-Patterns

- Blindly replacing established design tokens, adding visual noise, or sacrificing usability for decoration.

## Completion Criteria

UX improvements are verified in the browser across viewports with no regressions.
